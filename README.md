# HN-KS26-CNTT2_Nhap-mon-CNTT_OnTap-Ngay3 
# Dự án Website Trung tâm Tiếng Anh TTA

Website quản lý khóa học, học viên và học phí cho **Trung tâm Tiếng Anh TTA** (*TTA English Center*).

## Giới thiệu
Dự án được xây dựng nhằm tối ưu hóa quy trình đăng ký học, quản lý danh sách học viên và theo dõi doanh thu học phí hàng tháng.

## Cấu trúc thư mục

| Thư mục / File | Nội dung |
| :--- | :--- |
| `data/` | Chứa dữ liệu Excel về khóa học và học phí |
| `docs/` | Tài liệu hướng dẫn và quy định của trung tâm |
| `media/` | Chứa hình ảnh và tài nguyên truyền thông |

## Quy trình đăng ký học tại TTA
1. Học viên đăng ký thông tin và chọn khóa học phù hợp.
2. Trung tâm tư vấn, xác nhận học phí và gửi thông tin thanh toán.
3. Học viên hoàn tất thanh toán và nhận lịch khai giảng.

## Kiểm tra cấu trúc thư mục
```
Get-ChildItem -Recurse
```
